# Evidence-First Completion Gate

Completion is a claim backed by current evidence, not an assistant assertion.

- [ ] Every acceptance criterion maps to verification evidence.
- [ ] Each run command includes its result and relevant scope.
- [ ] Failures, skipped checks, and unavailable tooling are reported plainly.
- [ ] A reviewer can reproduce the stated validation from the report.
- [ ] Residual risk and next action have an owner when work is incomplete.

Use `templates/evidence-report.md` for the handoff. “Done” requires PASS evidence for every required applicable gate or an explicit approved exception.
