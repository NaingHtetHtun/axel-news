# /fix-bug

Select the owning agent using `agent-router.md`; load `bug-fix`, relevant memory, and the minimum skill plan.

1. Capture expected and actual behavior with scope and evidence.
2. Reproduce or bound the issue before editing.
3. Prove root cause, make the smallest repair, and add regression evidence.
4. Run `change-readiness` and `evidence-first` checks.
5. Return the Evidence Report with residual risk.
