# Before Edit Hook

1. Identify task outcome, scope, and whether this is analysis or a change.
2. Route to the primary agent.
3. Read relevant project memory and `rules/core-standards.md`.
4. Run the Skill Loader and present the minimum Skill Load Plan.
5. Inspect existing conventions and tests before modifying files.

Stop for clarification when a missing decision materially changes architecture, data, security, or destructive scope.
