# API Creation Workflow

Load `api-design`, `input-validation`, `security-baseline`, `error-handling`, and `testing-strategy`.

1. Identify consumers and their outcome.
2. Define request, response, authorization, pagination, idempotency, and error contracts.
3. Review compatibility, ownership, and data exposure.
4. Implement boundary translation and validation.
5. Test contract, authorization, validation, and failure behavior.
6. Publish examples and versioning guidance.
