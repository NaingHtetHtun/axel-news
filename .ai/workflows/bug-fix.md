# Bug Fix Workflow

Load `debugging-method`, `error-handling`, `testing-strategy`, and `code-review`.

1. Capture expected versus actual behavior and scope the impact.
2. Reproduce or bound the failure with logs, traces, and a minimal case.
3. State and test a root-cause hypothesis.
4. Apply the smallest corrective change.
5. Add a regression test and verify adjacent behavior.
6. Document root cause, risk, and follow-up prevention where needed.
