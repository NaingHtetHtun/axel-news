# Feature Development Workflow

Load `feature-planning`, `clean-code`, `testing-strategy`, `security-baseline`, and `code-review`.

1. Define outcome, acceptance criteria, constraints, and non-goals.
2. Inspect the affected boundaries and identify risks, data changes, and compatibility needs.
3. Plan small verifiable slices; decide observability and rollback before implementation.
4. Implement the smallest complete slice using shared rules.
5. Test behavior and failure paths at proportionate levels.
6. Review the diff against the original outcome, then document decisions and release evidence.
