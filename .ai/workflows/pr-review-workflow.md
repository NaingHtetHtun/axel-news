# PR Review Workflow

Load `code-review`, `security-baseline`, `testing-strategy`, and `git-conventions`.

1. Read intent, acceptance criteria, and risk notes before the diff.
2. Trace the main behavior and its boundary contracts.
3. Inspect security, data, error, concurrency, and release implications.
4. Assess test evidence and documentation.
5. Report evidence-backed findings by impact and verify follow-ups.
